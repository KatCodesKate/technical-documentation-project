Position Property

The positionproperty specifies the positioning method for an element.

The are five different position values:

  • Static
  • Relative
  • Fixed
  • Absolute
  • Sticky

position:static;

Static is the default position of all HTML elements.

Static positioned elements are not affected by top, left, bottom, right properties.

An element with position:static; is not positioned in any special way. It's always positioned according to the normal flow of the page.

This div is static.
HTML
<div class="static-div">This div is static.
</div>
CSS
.static-div{
border:2px solid blue;
position:static;
}

position:relative;

An element with position relative is positioned relative to its normal position.

Using the top, right, bottom, left properties of the relatively-positioned element will cause it to be adjusted away from its original position.

No other content will adjust to fit into the gap left by the element.

This div is relativeley positioned.
HTML
<div class="relative-div">This div is relative.
</div>
CSS
.relative-div{
border:2px solid blue;
position:relative;
left:50px;
}

position:fixed;

An element with position:fixed is positioned relative to the viewport, which means it always stays in the same place even if the page is scrolled.

The top, right, bottom, left properties are used to position the element.

A fixed element does not leave a gap in the page where it would have been normally located.

The nav bar on the left of the screen is fixed to the left.

CSS
#navbar{
position:fixed;
left:0;
top:0;
height:100%;
width:300px;
background-color:black;
color:white;
padding:10px;
z-index:999;
}

position:absolute;

The position:absolute is positioned relative to the nearest positioned ancestor. (Instead of positioned relative to the viewport, life fixed.)

If an absolute positioned element has no positioned ancestors, it uses the document (HTML) body, and moves along with page scrolling.

Note: Absolute positioned elements are removed fron the normal flow, and can overlap other elements.

This div is absolute.

position:sticky;

An element with position:sticky is positioned based on user's scroll position.

A sticky element toggles between relative and fixed, depending on the scroll position.

It is positioned relative, until a given offset position is met in the viewport - then it sticks in place (like position:fixed).

Note:At least one of the top, right, bottom, left, must be specified, for sticky position to work.

z-index Property

When elements are positioned, they can overlap other elements.
The z-index property specifies the stack order of an element. (Which element should be placed in front, or behind, the other.).

  • z-index only works on positioned elements (position:absolute, position:relative, position:sticky; position:fixed), and flex items (elements that are direct children of display:flex;).
  • If two positioned elements overlap without a specified z-index, the element positioned last in the HTML code will be on top.
  • An element can have a positive or negative stack order.

z-index 1/-1/999

Use z-index 999 when:

  • You need an element to appear above most elements.
  • You are certain it won't conflict with high priority layers.
  • You are not arbitrarily stacking elements with big numbers just to "make it work".

Use z-index 1/-1 when:

  • You want an element to be just above/below its sibling, nothing too extreme.
  • To avoid using large z-index values and keep the stacking order clean.
  • The element must not go on top of evereything else, just its local context.

CSS Colors

The Two Main Color Models

The are two main color models:

  • The additive RGB(R,G,B), used in electronic devices.
  • The substructive CMYK(Cyan, Magenta, Yellow, Black). Used in print.

1-RGB(R,G,B) Characterisitics

  • Starts as black at RGB(0,0,0), and changes as different levels of Red, Green and Blue are introduced.

2-Secondary Colors:

Secondary colors are combinations of primary colors.

  • Yellow is a combination of Pure Red and Pure Green.
    Yellow:rgb(255,255,0)
  • Cyan is a combination of Pure Green and Pure Blue.
    Cyan: rgb(0,255,255)
  • Magenta is a combination of Pure Red and Pure Blue.
    Magenta:rgb(255,0,255)

3-Tetriary Colors

Tetriacy colors are a combination of primary color and a nearby secondary color.

  • Orange is a combination of Max Red and mid-value Green.
    orange:rgb(255,127,0)
  • Spring Green is a combination of Max Green and Mid-value Blue.
    Spring Green:rgb(0,255,127)
  • Violet/Electric Purple is Mid Red and Max Blue.
    Violet:rgb(127,0,255)
  • Chartreuse Green is Mid Red and Max Green.
    Chartreuse Green:rgb(127,255,0)
  • Azure is Mid Green and Max Blue.
    Azure:rgb(0,127,255)
  • Rose/Bright Pink is Max Red and Mid Blue.
    Rose:rgb(127,0,255)

Color Theory

A color wheel is a circle where similar colors, or hues are near each other. and different ones are further apart.

Example: Pure red is between the hues orange and red.

Complementary Colors

  • Complementary colors are opposite from each other on the color wheel.
  • If complementary colors are combined, they produce gray.
  • When place side-by-side, these colors produce strong visual contrast and appear bright.

The HSL Color Models

  • CSS HSL function accepts 3 values: A number from 0 to 360, a percentage for saturation and a percentage for brightness.
  • On color wheel, red is at 0 degrees, green is at 120, and blue is at 240 degrees.
  • Saturation is the intensity of color from 0% (Gray) to 100% pure color.
  • Lighness is how bright the color appears. 0% is complete black. 50% is neutral.

Gradients & Shadows

CSS Gradients

CSS gradients lets you display smooth transition between two or more specified colors.

CSS defines three types of gradients:

  • linear Gradient (goes down/up/left/right/diagonally)
  • Radial Gradients (defined by their center)
  • Conic Gradients (rotated around a center point)

CSS Linear Gradient

linear-gradient property creates a linear gradient where one color transitions into another.

Note:

  • Linear gradient creates an image element.
  • It is usually paired with background-image or just the 'shorthand' background

Color Stops

Color stos are colors you want to render smooth transition among. To create a linear gradient, at least two colors must be defined.

  • Allows to fine-tune where colors are placed along the gradient.
  • Length units like px or percentages can be used to determine where the transition begins.
  • A starting point and a direction (or an angle) can also be set.

Syntax

background: linear-gradient(direction, color-stop1, color-stop2 ...);

CSS

.linear-gradient-1{
background:linear-gradient(90deg, rgb(255,0,255), rgb(127,0,255));
color:white;
padding:20px;
text-align:center;
}

CSS Radial Gradient

The CSS radial-gradient() function creates a radial gradient.

A radial-gradient is defined by its center.

To create a radial-gradient, at least two color stops must be defined.

Syntax
background: radial-gradient ([shape] [size] at [position], start-color, ..., last-color);

Default is: Shape is ellipse. Size is farthest-corner. Position is center.

1-Shape
  • Determines whether the gradient is circular or elliptical.
  • Options:
    • circle: Forces the gradient into a perfect circile.
    • ellipse (default): Stretches based on the element's aspect ratio.

Example:

background: radial-gradient(circle, red, blue, purple);
2-Size

Defines the size of the gradient. It tells the gradient how far it should extend before reaching the last color stop.

It takes four values:

  • closest-side:Gradient stops at the nearest side of the box (top, right, bottom, left).
  • farthest-side: Gradient stops at the farthest side of the box.
  • closest-corner: Gradient stops at the closest corner of the box.
  • farthest-corner(Default):
    • Gradient stops at the fardest corner of the box.

Accessibility

What is Accessibility?

Accessibility (often abbreviated to A11y -- as in "a", then 11 characters, then "y") in web develpment means enabling as many people as possilbe to use websites, even when those people's abilities are limited in some way.

Accessibility means developing content to be as accessible as possible, no matter the individual's physical or cognitive abilities and how they access the web.

ARIA

Accessible Rich Internet Application (ARIA) is a set of roles and attributes that define ways to make web content and application (especially those developed with JavaScript) more accessible to people with disabilities.

  • ARIA Attributes

    • Enable modifying an element's states and properties as defined in the accessibility tree.

    Find more about ARIA attributes.

  • ARIA Roles

    • ARIA roles provide semantic meaning to content, allowing screen readers and other tools to present and support interaction with an object in a way that is consistent with user expectations of that type of object. ARIA roles can be used to describe elements that don't natively exist in HTML or exist but don't yet have full browser support.

    By default, many semantic elements in HTML have a role. For example, <input type="radio"> has the "radio" role. Non-semantic elements in HTML do not have a role. Elements like <div> and <span> without added semantics return null. The role attribute can provide semantics.

Find more about ARIA roles

The Region Landmark

The region role is an ARIA landmark role.

role="region" is used to identify a section of the page as an important landmark or region.

Purpose And Use

  • Improves accessibility: It tells users "this is a meaningful part of the page", so users can directly jumb to it.
  • Adds structure: Each region acts like a self-contained topic or section.

Use it when:

  • When the section contains important content that users might want to navigate to directly.
  • When the section has a visible heading (<h1> to <h6>), which helps screen readers label the region meaningfully.
  • The region landmark role's content should make sense if seperated from the main content of the document.

Every element with a role="region" should include a label that describes the purpose of the content in the region.

  • aria-labelledby should be used, referencing a visible header.
  • aria-label should be used if no visible appropriate header is present.

aria-labelledby VS aria-label

This is used to label a region.

Using aria-labelledby

  • aria-labelledby is often used to point to the heading of the section so screen readers mention the heading to refer to the region.
  • Use aria-labelledby when there is a visibile text/hading that can serve as title to the section, usually a heading <h> tag.
    1. Add an id to the element you want to use as label to the region (e.g, a heading tag).
    2. Add aria-labelledby to the element with role="region with the same value as the id of the element used to title the region.
Example:
<div role="region" aria-labelledby="region-heading">
<h2 id="region-heading">
Screen readers will read this heading.
</h2>

</div>

Using aria-label

  • Use aria-label when no appropiate visible appropriate heading.
  • This defines a label that is only visible to assestive technologies.
Example:
<div aria-label="contact information">
<p>Phone: 123-456-7890</p>
<p>Email: info@example.com</p>
</div>

Best Practice

Prefer HTML

  • Using the <section> element will automatically communicate a section has a role of region if it is given an accessible name.
  • Prefer using <section> whenever possible.

Developers should always prefer using the correct HTML semantic element, instead of using ARIA.

Labeling Landmarks

If there is more than one region landmark role, provie a unique label for each one.

The label will allow assistive technology users to be able to quickly understand the purpose of each landmark.

Examples:
Using a visible heading

This is the best practice and most recommended method, as it provides information to both screen readers and sighted users.

<section>
<h2>Contact Us</h2>
<p>Information about contacting us...</p>
</section>

When the heading <h> element is inside the section element, WAI-ARIA roles are not needed. HTML semantic element is enough.

Use aria-labelledby

To link the section to a visible element that serves as its label, such as a heading.

<h2 id="contact-heading">Contact Us</h2>
<section aria-labelledby="contact-heading">
<p>Information about contacting us...</p>
</section>

When the heading <h> element is before the section element, aria-labelledby should be used.

Use aria-label

If no visible label is required, you can provide an accessible name directly using aria-label.

<section aria-label="Contact Information">
<p>Information about contacting us...</p>
</section>

The label will only be visible to assistive technologies, and read by screen readers.

Hide Elements Visually For Screen Readers

It is possible to add text only screen readers can read.

Here is how:

  1. Nest the text you want to hide within a <span> element and give it a class.
  2. A common CSS code can be used to make the text visually hidden, only visible for screen readers to read.
The Code:
border: 0;
clip: rect(1px, 1px, 1px, 1px);
clip-path: inset(50%);
height: 1px;
width: 1px;
overflow: hidden;
white-space: nowrap;
position: absolute;
padding: 0;
margin: -1px;
Explanation:
  1. clip: and clip-path: are both used to maximize browser compatibility, especially for older browsers that don't support clip-path:.
    • clip: legacy property, supported by very old browsers (pre-2017).
    • clip-path: current spec, works in all modern browsers and isn't deprecated.
  2. clip: rect(1px, 1px, 1px, 1px); or clip: rect(0, 0, 0, 0); -- clips the element down to nothing.
    -Only works with position:absolute;. Hence, adding it.
  3. clip-path(50%); -- Newer syntax for modern browsers. Does the same as (2).
  4. overflow: hidden; width: 1px; height: 1px; margin: -1px; -- help push the element off screen and prevent it from affecting layout.
  5. white-space: nowrap; -- avoids line breaks, just in case.
    (The white-space property specifies how the white space inside an element is handled).
Alternative Code

Using an example:

  1. Nest the text you want to hide in a span element and give it a class.
  2. Give the class the CSS code to make the text hidden.
HTML

<p>Some text and <span class="sr-only">word</span> within span to make it hidden.<p>
CSS

position: absolute;
width: 1px;
height: 1px;
overflow: hidden;
clip: rect(0, 0, 0, 0);
clip-path: inset(50%);
white-space: nowrap;
Final Note

This combo of code is often used for screen readers only content. Such as:

  • Form labels that are hidden for visual users, but announced by screen readers.
  • Extra descriptions or accessibility helpers for blind users.

CSS Functions

CSS functions can be used to calculate values, manipulate strings or colors, create complex shapes and gradients, and more.

CSS calc() Function

Allows to perform calculation to determine the value of a property.

Example 1:

To calculate the width of a div element.

Creates a div that stretches across the window, with 50px gap on both sides.
.calc-div1{
background-color:yellow;
border:1px solid black;
width: calc(100% - 100px);
padding:5px;
position:absolute;
left:50px;
}
Explanation:
  1. position:absolute; Takes the element out of the document flow and positions it relative to the html page (in this case).
  2. left:50px; Moves the div 50px from the left.
  3. width: calc(100% - 100px); Sets the div width to 100% minus 100px.

    why 100px? Becaus:

    • The div is already pushed 50px away from the left.
    • We want 50px gap on the right, too.

100% - 100px = div width - the combined left and right gaps.

Example 2:

This will make the div 50px narrower only on the right side.
.calc-div1{
background-color:yellow;
border:1px solid black;
width: calc(100% - 100px);
padding:5px;
}

Example 3:

padding: 0.5rem calc(1.25rem + 2px) 0.5rem 1rem;
Explanation:
  • Top: 0.5rem
  • Right: calc(1.25rem + 2px)
  • Bottom
    • : 0.5rem
  • Left
    • : 1rem
  • right padding is the only side using calc().
    calc(1.25rem + 2px) means: font-size-based value 1.25rem + fixed 2px.
  • If the root font size rem is the usual 16px: 1.25 x 16px = 20px. So padding-ight: calc(1.25rem + 2px) = about 22px.
Why use it

Combining a scalable unit (rem) with a fixed pixel tweak is common when you want padding that is mostly scales with text size, but still leaves a consistent extra amount of pixels -- for example to make room for an icon, border, or caret.

CSS min() Function

The CSS min() function uses the smallest value, from a comma-seperated list of values, as the property value.

Example:

In this example, the width will be at most 300px, but it will be smaller (50%) if the viewport width is smaller than 600px.

min() sets the width to whichever value is smallest: 50% or 300px.
This div has a fixed width of 300px.

Tip: You can think of min() function to set a maximum value for an element.
